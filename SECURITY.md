# Política de segurança

## Versões suportadas

O projeto ainda não possui release pública. Esta seção será atualizada quando existir uma versão suportada.

## Como reportar uma vulnerabilidade

Não abra uma issue pública para uma vulnerabilidade ainda explorável.

Use **Security → Report a vulnerability** no repositório GitHub para iniciar uma comunicação privada. Inclua impacto, passos mínimos de reprodução e, se possível, uma sugestão de correção. Não inclua dados pessoais reais nem execute testes destrutivos.

Confirmaremos o recebimento e coordenaremos divulgação depois que a correção puder ser distribuída com segurança. Prazos públicos serão definidos quando houver equipe e processo capazes de cumpri-los — e a decisão de manter este canal como o **oficial do lançamento**, com ou sem prazos publicados, está registrada e ainda **em aberto** em [docs/GOVERNANCE.md](docs/GOVERNANCE.md) (`security-channel`).

Requisitos técnicos e o checklist de release estão em [docs/SECURITY.md](docs/SECURITY.md).
